# Escape the Horror House

Welcome to my command-line maze based on horror movies.

Your goal is to navigate through references to popular horror movies and find the final escape file.

Useful commands:

- `ls` — list files and directories
- `ls -a` — show hidden files and directories
- `cd folder-name` — move into a directory
- `cd ..` — move back one directory
- `cat filename.txt` — read a file
- `pwd` — show your current location

Start by reading:

`entrance.txt`

the other file options:

- final-destination
- insidious
- saw
- scream
- the-conjuring

Good luck, and try not to get caught.
